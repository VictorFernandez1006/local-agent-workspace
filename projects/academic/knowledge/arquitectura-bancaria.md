# Arquitectura bancaria

Una arquitectura bancaria basada en
microservicios puede dividir sus capacidades
en servicios independientes.

Conceptos importantes:

- API Gateway.
- Autenticación y autorización.
- Orquestación.
- Mensajería.
- Persistencia.
- Auditoría.
- Observabilidad.

Los servicios deben definir contratos
de comunicación y mecanismos de resiliencia.
