# Compensaciones bancarias

Una compensación es un mecanismo utilizado
para gestionar situaciones en las que una
operación distribuida no puede completarse
correctamente.

En arquitecturas basadas en microservicios
pueden utilizarse patrones como Saga.

Las compensaciones ejecutan acciones
correctivas para contrarrestar operaciones
previamente realizadas.

Ejemplos:

- Reversar una reserva de fondos.
- Liberar recursos.
- Registrar el resultado de una operación.
